# 🌿 Wellness Companion

A cross-platform mental wellness mobile application designed to help users build healthier habits, track their well-being, and develop mindfulness through daily reflection, goal setting, and self-care routines.

![Screenshot](https://raw.githubusercontent.com/Leopoldov95/wellness-companion/main/wellness.jpeg)

> ⚠️ **MVP Status:** Social sign-on and notifications are planned but not yet implemented.

---

## 📱 Overview

Wellness Companion is a privacy-first mental wellness app that helps users:

- Set and track weekly wellness goals
- Log daily mood
- Practice gratitude journaling
- Gain insights into habits and emotional well-being
- Stay motivated through streaks, rewards, and gentle reminders

The goal is to encourage sustainable self-care habits without promoting excessive screen time.

---

## ✨ Key Features

### 🎯 Weekly Wellness Goals

- Set custom or suggested wellness goals (e.g., mindfulness, exercise, self-care)
- Track progress with visual indicators
- Build streaks and earn motivational rewards for consistency

### 😊 Mood Tracking

- Daily mood logging with optional notes
- Mood calendar view to visualize emotional trends
- Insights into mood patterns and activity correlations

### 🧘 Gratitude Journal

- Daily gratitude entries with optional prompts
- Streak tracking to encourage consistency
- “Gratitude Gallery” to revisit past entries

### 📊 Wellness Insights Dashboard

- Central overview of mood and goal progress
- Visual summaries of personal wellness trends
- Lightweight, at-a-glance experience

### 🎵 Meditation & Relaxation

- Calming background music and soundscapes
- Guided breathing exercises
- Mood-based or time-based playlists

---

## 🧠 Design Philosophy

- Minimal, calming, and distraction-free UI
- Focus on accessibility and mobile responsiveness
- Encourages healthy habits without over-engagement
- Privacy-first approach to personal wellness data
